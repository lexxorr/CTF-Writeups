Each writeup follows the same structure: **Analysis → Exploitation → Flag**

## Writeup format

Every writeup follows a consistent skeleton so techniques stay easy to scan and compare across challenges:


- **Analysis** — understanding the target, source code review, file or traffic inspection
- **Exploitation** — the full path to the solution, including any dead ends worth noting
- **Flag** — the validation password

## Disclaimer

All writeups document activity performed exclusively on Root-Me's own challenge platform, under its terms of use. Passwords and flags shown are specific to the challenges and hold no value outside that context.
